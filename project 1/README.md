# TechPulse — Tech News Magazine

## Description
A static tech news magazine webpage built with pure HTML and CSS. Features a professional magazine-style layout with hero section, news cards, trending sidebar, and newsletter subscription.

## Features
- Semantic HTML5 structure
- CSS Grid & Flexbox layout
- Google Fonts — Inter
- Responsive design
- W3C Validated

## How to Run
1. Download the project folder
2. Open `index.html` in any browser
3. No installation required!

## Tech Stack
- HTML5
- CSS3
