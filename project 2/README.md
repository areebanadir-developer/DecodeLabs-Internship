# FitZone — Responsive Fitness Landing Page

## Description
A fully responsive fitness app landing page built with HTML, CSS, and JavaScript. This project covers Project 2 (Responsive Layout) and Project 3 (Interactive Web Elements) of DecodeLabs Internship.

## Project 2 — Responsive Web Layout
- Mobile-first CSS approach
- CSS Media Queries — 3 breakpoints
- **Hamburger Navigation Menu** — mobile mein ☰ button
- CSS Grid & Flexbox layout
- Fluid typography with clamp()
- Responsive images and sections

## Project 3 — Interactive Web Elements
- Dark/Light Mode Toggle 🌙
- FAQ Accordion — open/close on click
- Contact Form Validation
- Scroll animations — Intersection Observer
- JavaScript DOM Manipulation
- Event Listeners
- classList.toggle() for state management

## How to Run
1. Download the project folder
2. Open `index.html` in any browser
3. No installation required!

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
